# Sandbox architecture walkthrough

[Open the interactive walkthrough](https://justinwlin.github.io/runpod-sandbox-architecture/).

Explore browser JWT, unattended API-key and OAuth designs, with a combined view of chat, credentials, API operations, history and expiry. This is an illustrative architecture proposal, not a deployed authentication service. It uses no real credentials or user data.

GitHub Pages publishes this standalone HTML from the main branch. No build or dependencies are required.
